# 享阅（XiangYueAPP）

## (Client / XiangYueServer）

**学习资源共享平台** - 基于 Qt Widgets + TCP 的高并发网络应用示例

**关键特性**：支持 **并发连接**、**多文件资源上传**、**资源评论系统**、**文件预览**、**标签搜索（HNSW）**

使用**Qt6.10.3**(以防无法使用PDF预览模块)

该服务端可在Windows和Linux上运行

如果要打包客户端记得修改logdialog.cpp中connectToHost后的IP
